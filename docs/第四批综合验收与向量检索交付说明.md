# 第四批交付：全 Agent 综合验收与 S17 向量检索

本批把病史、认知、检验、影像四类 Agent 纳入 S14–S16 的统一协议验收，并接入真实 BGE-M3 向量检索。BM25、基础 Neo4j 查询和向量结果使用同一来源契约，按简单排名融合；没有增加复杂重排器、条件树或图路径推理作为文本流程的前置依赖。

工程协议通过不代表医学判断准确；S12 的 DiaMond 真实推理一致性仍是独立阻断项。

## S14–S16 的完善

| 模块 | 输入 | 输出与约束 |
|---|---|---|
| 主 Agent 复查 | 当前专业结果、其原文观察、病例资料盘点、其他专业最新主张与时间、检索证据 | 定向 ReviewRequest；目标仅限当前专业已有 claim；不同日期不自动视为冲突，不以角色投票定诊断 |
| 各专业 review | 问题、目标结果版本、当前授权原文和证据 | corrected / clarified / maintained_with_evidence / unresolved；响应必须绑定原请求及正确版本 |
| 最终汇总 | 各专业最新有效主张 | 同源事实去重；跨 Agent 同名 claim_id 消歧；不引入无来源的新结论 |
| ClaimDependency | task_id、result_id、result_version、原 claim_id | 每条报告主张记录来源专业及版本；报告 JSON 和 Markdown 均可核对 |
| 准备阶段恢复 | 已保存 patient_input、原运行配置/预算/截止时间、知识绑定与各阶段产物 | 复用 intake、附件解析、snapshot、plan；准备文件尚未生成也可 resume，不重置预算 |
| `audit_run` | run_id、已保存快照、计划、各版结果、报告、检索与工具记录 | acceptance.json：协议检查、错误、调用统计、未完成的外部验收项 |

复查时其他专业只提供最多六条主张及其原文/时间摘要，并明确 omitted_claim_count；这属于有界上下文，不宣称已完成任意规模病例的穷尽冲突检查。

执行状态与判断状态分开：存在未完成任务或降级时为 partial；复查未决为 unresolved，有受限解释时为 conditional，仅事实不足以判断时为 insufficient_data。没有因流程完成而自动升为 supported_tendency。

准备阶段恢复从 patient_input 成功落盘开始；若进程在保存首份输入之前终止，没有足够输入可恢复。已发出但未确认落盘的外部调用仍计入原预算，可发生受预算限制的重试，不声称外部请求恰好执行一次。

### 统一测试覆盖

四类真实 handler 的 review 均参与协议测试：纠正“未提供”误写成阴性、有原文依据地维持结论、单专业复查失败不抹掉其他专业、过期版本不能进入汇总、报告写入中断后重放不重新调用模型、准备阶段快照恢复、预算过期返回有限资料。

协议测试使用明确的模型替身；下文真实运行单独验证模型和检索服务。基础第三批测试继续覆盖未知量表、缺单位/方法、跨日期保留、影像准入、工具结果校验与超时清理。

## S17：版本固定的向量索引

新增核心文件：

- `knowledge/indexing/vector.py`：EmbeddingClient、VectorIndexManifest、索引构建与余弦检索。
- `clinical/vector.py`：发布来源验证、离线构建适配、在线向量检索。
- `clinical/retrieval.py`：BM25 / vector / graph 结果恢复为同一 EvidenceItem，做 RRF 融合。
- `clinical/evaluation.py`：固定查询集对照与分开的 Hit@K / Recall@K。
- `clinical/acceptance.py`：全流程确定性协议检查。

| 项目 | 本次配置/实现 |
|---|---|
| 服务 | 本地 Ollama；没有下载新模型，也没有向外网发送病例 |
| 嵌入模型 | `bge-m3:latest` |
| 固定模型摘要 | `7907646426070047a77226ac3e684fbbe8410524f7b4a74d02837e43f2146bab` |
| 维度 | 1024；不匹配则拒绝该后端 |
| 文本视图 | `retrieval_text_prefix_v1`，每个已发布 child chunk 的前 1800 字符 |
| 归一化/相似度 | L2 / cosine；非有限值、零向量、异常维度拒绝 |
| 发布版本 | `release_89168ff3faf8e2baf5b278772b25b0e398f04d2b423274e582fb8f326213e69a` |
| 索引 | `vector_f17bed05a0f4159c607f47e22235af51`，46 个文本块 |
| 存储 | 本地不可变目录，manifest.json + vectors.json；适用于当前小规模知识库，不是大型 ANN 服务 |
| 融合 | RRF：每个后端对同一 span 只计一次排名，分数为各后端 `1/(60+rank)` 之和，再按来源去重 |

构建输入为已发布、审核过的 chunk；同时检查发布文件校验和、chunk 集合、span/document 归属。VectorIndexManifest 固定 release、模型摘要、维度、文本视图、归一化、语料哈希、chunk 列表与向量文件校验和。查询前后核对模型摘要，不允许同名标签替换权重后继续混用旧索引。

索引按新目录原子发布，失败的构建不覆盖现有索引。基础 ReleaseManifest 不被原地修改，向量索引作为绑定该发布的独立版本产物。运行开始固定向量 manifest 的哈希；续跑中索引变化则仅拒绝向量后端，不偷偷切换新索引。

当前前缀视图可能遗漏长块尾部信息，后续可另建版本进行对照；本批不声称这种截断策略最优。大语料 ANN、交叉编码器重排、患者条件适用性算法和复杂图路径留在后续优化。

## 检索统一契约与降级

向量只返回既有 chunk ID，证据正文从知识注册库的原始 span 恢复，不把向量库变成没有来源的新文本库。BM25 同样改为引用对应 span 原文，保留上下文；同一来源的 matched_by、backend_ranks、clause_ids 合并。

EvidenceItem 新增 backend_ranks、fusion_score；EvidenceBundle 新增 retrieval_metadata，记录索引 ID、模型摘要、维度、文本视图与融合方式。检索排名和分数不会提升证据的 allowed_use，默认仍为 background、applicability=unknown。

向量未配置/未建索引、超时、摘要/维度/发布不匹配或文件损坏时，该后端返回明确状态，BM25 仍可完成。向量查询整体设时间上限并受运行剩余时间限制；不在患者分析途中自动建库或拉取模型。

基础图谱查询继续使用 S07 的有证据关系与发布内 clause/span 约束。本批修正了允许 span 集合的读取方式：应从发布的 Chunk 对象获得 span_ids，不能把 chunk_id 字符串当成 Chunk 传入 citation resolver。基础查询按 claim_id/span_id 固定返回顺序以便重复对照，没有增加复杂图推理。

## 检索对照：固定查询，不宣称提升

`tests/fixtures/retrieval_queries.json` 在本次对照执行前固定了 4 条 dev、4 条 heldout 查询及来源页/span 标签。标签依据本地来源审阅构建，状态为 `assistant_source_reviewed_not_expert_gold`，不是临床专家独立审定的完备金标准。

指标口径：Hit@K 是该查询前 K 项是否命中至少一个已标注相关来源；Recall@K 是命中的已标注相关来源数 / 该查询已标注相关来源总数，再按查询平均。这里的 Recall 只针对该标注集合。

| 集合 | 方法 | Hit@5 | Recall@5 |
|---|---|---:|---:|
| dev（4 条） | BM25 | 1.000 | 1.000 |
| dev（4 条） | 向量 | 1.000 | 0.875 |
| dev（4 条） | BM25 + 向量 + 基础图谱 | 1.000 | 1.000 |
| heldout（4 条） | BM25 | 1.000 | 1.000 |
| heldout（4 条） | 向量 | 1.000 | 1.000 |
| heldout（4 条） | BM25 + 向量 + 基础图谱 | 1.000 | 1.000 |

本次 24 次真实检索均完成；带固定候选术语的八条 hybrid 查询中三个后端均返回结果。这个小样本没有显示融合优于 BM25，不据此报告检索质量提升或诊断准确率。

## 使用与复现

默认配置 `configs/clinical.default.yaml` 已启用本地已构建索引。若在新环境中缺少索引，文本检索会降级，先执行构建并将返回的 manifest 路径填入 `vector.index_manifest`。构建命令不会悄悄修改配置或已有发布。

```powershell
$env:PYTHONPATH = "$PWD/code"
python -m neurogra.clinical.cli build-vector-index
python -m neurogra.clinical.cli analyze --patient code/neurogra/clinical/tests/fixtures/multispecialty.json
python -m neurogra.clinical.cli audit-run --run-id <运行ID> --require-all-agents
python -m neurogra.clinical.cli resume --run-id <运行ID>
python -m neurogra.clinical.cli evaluate-retrieval --queries code/neurogra/clinical/tests/fixtures/retrieval_queries.json --top-k 5
```

本批最终自动化检查：93 项 clinical 测试 + 18 项 knowledge 回归测试，共 111 项通过。新增测试包括全专业纠正/维持/失败隔离/恢复、过期依赖拒绝、向量模型/维度/语料/索引损坏校验、超时降级、RRF 去重和指标口径。检索对照没有同时调专业提示词来主张检索收益；新的跨专业复查上下文只用于流程集成验证。
