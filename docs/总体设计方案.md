# NeuroGRA：基于知识图谱与多智能体协作的神经退行性疾病辅助鉴别诊断研究方案

**文档类型：课题总体设计方案**  
**更新日期：2026 年 9 月 21 日**  
**研究阶段：方案设计，相关方法及效果有待实现与验证**

## 1. 研究背景与问题

神经退行性疾病相关认知障碍的诊断需要综合病史、认知评估、影像、检验及其他临床资料。不同病因可能表现出相似症状，同一患者也可能存在多种病因共同贡献。实际就诊时，可获得的数据往往不完整，不同来源的信息还可能存在差异。因此，辅助诊断系统需要支持候选病因之间的比较，说明判断依据，并交代现有资料对判断范围的限制。

以单一疾病判别或有限类别分类为目标的研究，为疾病识别提供了基础，但分类结果本身难以完整回答临床鉴别中的问题：为什么考虑某一病因，其他病因为什么仍需保留，哪些表现可能由多种病因共同解释，以及当前结论还有哪些不确定性。已有研究已经开展多病因及混合病因分析，因此，本研究不以“首次实现多病因诊断”为前提，而关注鉴别判断、医学依据与患者资料之间的有效结合。[1]

### 1.1 核心问题一：面向多病因可能性的辅助鉴别诊断

系统需要从患者的整体资料出发，比较不同候选病因的支持依据、限制因素和相互关系。研究既关注主要诊断倾向，也关注其他可能病因及共同贡献，避免将复杂病例简单归入一个互斥类别。

其中，“尚无法区分两种病因”和“有证据支持两种病因并存”属于不同情况。前者意味着鉴别仍未完成，后者需要分别支持不同病因的患者证据。系统应在报告中明确表达这种区别。

### 1.2 核心问题二：形成可追溯、有依据的诊断报告

辅助诊断报告需要说明结论来自哪些患者发现，这些发现依据什么医学知识得到解释，以及它们如何共同支持当前判断。仅输出疾病名称、概率或若干文献引用，尚不足以形成可核查的诊断依据。

本研究所指的证据链，是患者资料、医学依据与报告结论之间可核对的支持关系。它帮助医生检查判断是否合理，不等同于模型内部思维过程，也不直接代表疾病的因果机制。

### 1.3 贯穿两项问题的现实条件：临床资料不完整

资料缺失既影响病因鉴别，也影响报告能够作出的结论。系统应说明缺少哪些信息、这些信息与哪些判断有关，以及当前仍可得到什么结论。

因此，缺失数据处理纳入有依据的诊断分析全过程。研究关注在不完整信息下开展合理分析，而非通过生成内容补齐所有检查结果。例如，未记录某种表现不能直接解释为该表现不存在，未开展某项检查也不能解释为检查阴性。

## 2. 研究目标与范围

### 2.1 总体目标

构建 NeuroGRA 辅助鉴别诊断系统，通过多智能体分工处理异构患者资料，利用知识图谱与文本知识库提供医学依据，生成包含诊断倾向、鉴别分析、证据来源和资料局限的报告。在此基础上，引入经医生审核并获得相应授权的病例经验库，为后续病例提供历史参考。

### 2.2 研究范围

首期研究聚焦认知障碍场景，重点覆盖阿尔茨海默病、额颞叶变性相关病因及路易体相关病因，并将血管性贡献纳入鉴别与并存分析。血管性贡献作为相关因素处理，不归入神经退行性疾病类别。

系统根据资料条件分别描述认知状态、临床表现及候选病因，避免把认知障碍程度与具体病因混为一个分类问题。首期输入包括病史、认知量表、检验记录、影像报告及经过验证的工具结果。原始影像直接分析可在具备数据与工具条件后扩展。

系统面向医生提供辅助分析，最终诊断由医生结合临床情况作出。研究以鉴别诊断及其解释为中心，治疗决策不作为首期任务。

### 2.3 主次安排

| 层次 | 内容 | 在课题中的定位 |
|---|---|---|
| 核心研究 | 面向鉴别诊断的知识图谱与知识库构建、检索及应用 | 主要方法研究，决定系统如何使用医学知识支持判断 |
| 系统组织 | 不同数据类型的多智能体分析与综合 | 承载核心方法，完成多源患者信息的协作处理 |
| 输出要求 | 有依据的报告与缺失信息说明 | 贯穿系统流程，是评价研究效果的重要依据 |
| 扩展研究 | 医生审核病例的积累与参考 | 在基本系统完成后，验证历史经验带来的额外价值 |

## 3. 总体设计

系统由患者资料接入、多智能体分析、共享知识服务、综合鉴别与报告、医生审核及病例积累五部分组成。

患者资料接入后，系统根据实际可用的数据安排相应智能体分析。各智能体围绕自身任务检索共享的医学知识，形成带患者依据和知识来源的分析结果。综合分析模块进一步比较候选病因，组织支持证据与限制因素，形成诊断报告。医生可以审核和修改报告；满足授权及入库要求的病例进入经验库，供后续分析参考。

| 模块 | 主要职责 | 主要产出 |
|---|---|---|
| 患者资料接入 | 整理病史、评估和检查资料，保留时间与来源，标明缺失项 | 可供分析的患者资料 |
| 多智能体分析 | 按数据类型解读发现，结合医学知识说明其意义 | 各类数据的分析结论及依据 |
| 共享知识服务 | 提供图谱关系、指南原文和适当的历史病例参考 | 与当前任务相关的知识与来源 |
| 综合鉴别与报告 | 融合多源发现，比较候选病因，说明资料局限 | 可供医生审核的辅助诊断报告 |
| 医生审核与病例积累 | 记录医生修正及确认状态，按授权管理参考病例 | 经审核的病例经验与更新记录 |

各智能体使用同一套受管理的知识来源，避免不同角色依据不一致的材料作出判断。病例经验作为补充参考，与指南和研究证据保留明确的来源区别。

## 4. 核心研究：知识图谱与知识库的构建、检索及应用

### 4.1 构建面向鉴别诊断的医学知识体系

知识建设应围绕具体诊断问题展开。除疾病与症状之间的一般关联外，还需要覆盖不同病因的共同表现、具有鉴别意义的特征、相关检查的解释、适用条件，以及可能并存的情况。

文本知识库保存指南、共识及相关研究中的完整表述和出处；知识图谱组织疾病、表现、检查、条件和来源之间的联系。两者相互关联，使系统既能利用结构化关系寻找线索，也能回到原文核对医学主张。

| 知识内容 | 服务的诊断需求 |
|---|---|
| 疾病、表现与检查之间的关系 | 解释患者发现可能提示哪些病因 |
| 候选病因之间的共同点与差异 | 支持鉴别，避免只返回疾病的一般介绍 |
| 证据的适用条件和局限 | 判断某项知识是否适用于当前患者 |
| 多病因可能并存的相关知识 | 支持共同贡献分析，避免默认候选互斥 |
| 原文出处与版本 | 使报告依据可核对、可更新 |

知识来源优先采用权威指南、专业共识及与研究范围直接相关的文献。知识抽取后需要核对原文，重点检查诊断条件、否定表述和例外情况。首期围绕选定病因建立范围清晰的知识体系，并通过实际鉴别问题检查知识覆盖情况。

### 4.2 面向不同分析任务检索知识

不同智能体需要的知识并不相同。认知评估分析需要理解认知领域受损的意义，影像分析需要理解报告发现及其鉴别价值，检验分析需要关注检测结果的适用条件和解释范围。

检索应结合当前患者已有信息、智能体承担的任务及需要比较的候选病因。相关结果不仅要与疾病名称相近，还应有助于回答当前问题，例如某项发现能否区分两个候选、某项检查需要什么条件才能解释，以及哪些信息仍不足以支持判断。

研究重点在于如何联合利用图谱关系与文本原文，找到具有鉴别价值且适用于当前病例的知识。具体检索与排序方法将在原型阶段比较确定，总体方案不预先绑定某一种技术实现。

### 4.3 将检索知识应用于患者分析

知识应用需要建立患者发现与医学依据之间的对应关系。系统应能够说明：患者具有什么表现，该表现如何被相关知识解释，能够支持何种程度的判断，以及是否存在未满足的条件。

在多病因鉴别中，综合分析应同时考虑不同候选的支持依据和限制因素。在资料缺失时，系统应区分医学知识尚未找到与患者事实尚不清楚：前者可以进一步查找知识，后者需要核对已有患者资料，或在报告中保留未知及其影响。

这一研究环节的重点是使知识真正参与诊断分析和报告形成。多轮检索、来源核对等机制可作为实现手段，根据病例分析中出现的问题逐步完善。

## 5. 多智能体协作设计

多智能体按患者数据类型分工，以适应不同资料的解读特点。角色设置保持相对简洁，分析任务依据可用资料安排。

| 角色 | 主要任务 |
|---|---|
| 病史分析智能体 | 分析起病方式、病程变化、既往史及日常功能等信息 |
| 认知评估智能体 | 分析量表及认知领域表现，说明相应解释与局限 |
| 影像分析智能体 | 解读影像报告或工具结果，提取与鉴别有关的发现 |
| 检验分析智能体 | 分析实验室检查及生物标志物资料，关注适用条件 |
| 综合分析智能体 | 综合各方发现，比较病因，组织证据并形成报告 |

各分析智能体提交关键发现、解释依据和信息局限，综合分析智能体负责跨来源整合。多个智能体的意见一致不能代替患者证据；当意见不一致时，应检查其依据和适用条件。

某类数据缺失时，系统可以继续分析其他资料，并交代缺失造成的影响。多智能体架构的价值将通过与单智能体方案的对照验证，重点考察信息整合和报告质量，而非以角色数量作为效果依据。

## 6. 诊断报告设计

报告应让医生能够迅速了解主要判断，并进一步核查依据。建议采用以下结构。

| 报告部分 | 内容 |
|---|---|
| 病例概况 | 与本次分析相关的主要表现、病程和可用资料 |
| 主要判断 | 当前诊断倾向及判断能够达到的层次 |
| 鉴别分析 | 其他候选病因、支持与限制因素，以及可能并存的依据 |
| 证据说明 | 关键患者发现、医学依据及其与结论的对应关系 |
| 资料局限 | 缺失或不一致的信息，以及对具体判断的影响 |
| 后续评估方向 | 为进一步区分候选或核实判断，可供医生考虑的信息需求 |

关键结论应能够追溯到患者原始资料与医学知识来源。历史病例如参与分析，应标明其参考性质，并说明与当前患者的主要相似点和差异。

缺失说明需要具体对应诊断问题。例如，与其笼统表述“资料不足”，报告应说明哪部分资料缺失、因此哪项鉴别暂不能完成，以及已有信息仍支持哪些判断。系统也应保留合理的已知结论，避免将任何缺失都转化为整份报告无法作答。

## 7. 扩展设计：经医生审核的病例经验库

### 7.1 设计目的

医学知识提供一般性的诊断依据，历史病例提供实际患者中多种信息如何共同出现、如何被解释的参考。系统拟在获得相应授权的前提下，积累经医生审核的病例，使后续分析能够参考与当前患者有关的实际经验。

病例经验检索已有相关研究基础，其在本任务中的收益仍需验证。[3] 本项目首先通过病例库更新实现经验积累，模型持续训练不作为首期要求。

### 7.2 病例入库与更新

一次分析完成后，由医生审核患者信息与报告，修正不准确内容，并记录最终判断及其确认程度。只有满足存储和后续使用授权要求的病例，才进入参考库。入库内容经过必要的去标识化处理，并限定访问范围。

病例应保存关键临床资料、当时的缺失信息、医生审核后的判断及依据。后续随访或检查改变诊断时，应保留更新记录，避免继续使用已经失效的结论。医生审核认可、临床诊断和进一步证据确认等状态应分别记录，不将所有入库病例视为同等确定。

### 7.3 历史病例的参考方式

相似病例检索应综合关键表现、病程、检查结果及资料完整度，关注与当前鉴别问题有关的相似性。系统需要说明历史病例为何值得参考，以及哪些差异会限制类比。

历史病例可以提示值得核对的病因或证据，但不能替代当前患者的事实，也不能以相似病例的检查结果填补当前患者的缺失项。病例经验与指南不一致时，应保留差异并核查其原因。

## 8. 数据与验证方案

### 8.1 数据准备

病例数据的选择应服务于实际研究任务。优先寻找同时包含多类临床资料及不同病因标签的数据；混合病因分析还需要主要病因、伴随病因或共同贡献等相应标注。仅具有有限分类标签的数据，可以用于对应任务与报告分析，但不足以验证完整的多病因识别能力。

数据准备阶段应明确可用模态、缺失情况、标签含义和患者数量，并建立知识来源清单。数据划分以患者为单位，诊断结果及评估时点之后的信息不得泄露到待诊断输入中。病例经验库同样与测试患者隔离。

### 8.2 围绕研究目标开展评价

| 评价方面 | 重点问题 | 主要观察内容 |
|---|---|---|
| 辅助鉴别能力 | 能否合理识别、比较候选病因？ | 与标签对应的诊断表现、候选遗漏及混合病因判断 |
| 知识检索质量 | 是否找到当前鉴别需要的知识？ | 相关性、鉴别价值、适用性及依据完整程度 |
| 报告证据质量 | 结论是否得到患者资料和医学知识支持？ | 依据可追溯性、引用支持程度及关键事实遗漏 |
| 不完整资料下的表现 | 是否合理说明缺失带来的影响？ | 虚构患者信息、过强结论及有依据的回答覆盖 |
| 病例经验的增量价值 | 参考历史病例是否改善分析？ | 诊断与报告质量变化，以及错误类比情况 |

资料缺失评价同时考虑自然缺失病例和受控删除部分信息的病例，区分真实临床缺失与模拟情形。评价应兼顾错误减少与有效信息保留，避免仅因系统少作判断而得到表面改善。

### 8.3 对照安排

首先比较文本知识检索与图谱、文本联合检索，检验知识组织方式的价值；随后在相同知识条件下比较单智能体与多智能体，检验分工协作的作用；最后比较加入病例经验库前后的结果。

MedCoRAG 已结合知识图谱、指南检索与多智能体协作，是重要的相近工作。[2] 可在研究任务和实现条件允许时设置其适配方案作为对照，并说明适配范围。比较时控制基础模型、可用资料和资源预算，避免将额外调用带来的收益全部归因于方法本身。

报告质量可结合结构化检查与专业人员评阅，重点核对患者事实、医学依据和结论之间的关系。研究阶段不预设提升幅度，最终结论依据实际结果形成。

## 9. 实施安排与预期成果

实施遵循先明确任务与数据、再建设知识方法、随后集成系统、最后验证扩展的顺序。

| 阶段 | 主要工作 | 阶段成果 |
|---|---|---|
| 第一阶段：任务与资料准备 | 明确病因范围、报告要求、病例标签及知识来源 | 任务说明、数据清单与代表性病例 |
| 第二阶段：知识构建与检索 | 建立初步图谱和文本知识库，验证鉴别知识能否被有效获取 | 知识体系与检索原型 |
| 第三阶段：分析与报告 | 集成多智能体分析，形成证据可追溯且说明资料局限的报告 | 可运行的辅助鉴别诊断原型 |
| 第四阶段：病例经验扩展 | 加入医生审核、授权入库和相似病例参考 | 病例经验库与使用流程 |
| 第五阶段：综合验证 | 完成对照实验、专业评阅与失败病例分析 | 实验结果、适用边界及研究文档 |

预期成果包括面向所选病因范围的知识图谱与文本知识库、相应的知识检索及应用方法、多智能体辅助鉴别诊断原型，以及经审核病例经验的积累与参考机制。

课题的主要研究价值由知识构建、检索和应用能否改善鉴别分析及报告依据来体现。多智能体协作和病例经验库的作用分别验证，最终按实验支持的范围总结方法贡献。
