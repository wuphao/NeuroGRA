# NeuroGRA 总体架构图

本图展示研究设计，而非已经验证的诊断效果。共享医学知识支持不同数据类型的智能体分析及综合鉴别，输出与患者发现和医学依据对应的报告。经医生确认或修正、获得授权并完成去标识化的病例可纳入病例库，为后续诊断提供类似病例参考。

医学知识层突出知识构建、组织、检索和应用。临床主流程同时关注候选病因比较、多病共存依据以及缺失数据对判断的影响。多个候选病因尚未排除，不等同于已经确立混合病因；病例与文献均不能补写当前患者缺失的事实。

蓝色表示临床分析，绿色表示共享医学知识，棕色表示病例经验积累；棕色虚线表示历史病例的参考作用。箭头表示主要逻辑关系，未展开每轮检索和智能体调用细节。
