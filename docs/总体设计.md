# 神经退行性疾病辅助诊断项目研究方案

研究主题：基于知识图谱与多智能体的神经退行性疾病辅助诊断研究  
版本日期：2026 年 10 月 9 日

## 1 项目定位与研究目标

本研究以提高神经退行性疾病辅助诊断的准确率为首要目标。系统综合患者病史、认知量表、医学影像及实验室检验，通过保留医学知识的适用条件、诊断用途和来源，组织多智能体开展患者分析、证据检索与综合判读，形成具有明确证据依据的辅助诊断报告。

知识图谱、多智能体和证据追溯共同服务于诊断准确率提升。条件化知识构建用于减少知识限定丢失，患者条件判断用于减少不适用证据的使用，需求驱动的补查用于缓解关键知识遗漏，多智能体协作用于综合不同资料中的诊断线索。这些作用均属于需要验证的研究假设。

### 首要目标与辅助目标

首要目标是在预先确定的诊断任务和独立测试集上，相对于合理基线提高最终诊断准确率。评价应统一患者输入、可用知识范围和诊断标签，并说明模型能力及计算预算对结果的影响。

辅助目标包括改善知识声明的完整性、条件绑定的正确性、证据检索的适用性以及结论的可追溯性。这些指标用于解释诊断表现变化。仅有中间指标改善，尚不能证明首要目标已经实现。

### 研究对象与任务边界

题目覆盖神经退行性疾病，当前方案的背景和相关研究主要集中于痴呆、认知障碍及阿尔茨海默病。实施前需要固定目标疾病范围，并在认知状态分类、病因鉴别或其他诊断任务中确定一个主要任务。不同任务分别报告结果，不将不同标签体系下的准确率混为一项结果。

病史、量表、影像及检验是患者侧输入；指南、诊断标准和研究文献是知识侧输入。最终输出包含结构化诊断结果及辅助诊断报告。报告组织辅助判读、关键证据、推理依据与风险建议，其中结构化诊断结果承担准确率评价。

### 总体工作流程

1. 解析医学文档并构建保留条件、用途和来源的知识声明。
2. 将患者资料整理为带有出处、时间和缺失状态的患者事实。
3. 各分析智能体根据患者事实和诊断用途提出检索请求。
4. 混合检索候选知识，判断患者是否满足其适用条件。
5. 针对关键缺口补查资料或文献，核验后更新证据与判断。
6. 主智能体综合有效证据，输出诊断结果和可追溯报告。

## 2 研究问题与准确率提升机制

诊断判断同时依赖患者事实与医学知识。患者资料可能分散、缺失或存在表面冲突，医学知识则可能带有方法限制、适用条件及排除事项。系统需要将二者连接，使诊断判断建立在与当前患者及任务相适应的证据上。

### 知识限定如何完整保存

一条医学声明的主要结论和限定信息可能分别出现在正文、标题、表格、角标或脚注中。抽取时需要识别这些信息，并确定每个限定究竟约束哪条声明。研究问题是如何结合文档结构与医学语义，恢复具有正确约束范围的知识单位。

### 检索知识如何适用于当前患者

语义相关的知识可能具有当前患者尚未满足或无法确认的条件。研究问题是如何同时利用患者事实和诊断用途筛选候选证据，并保留满足、未知和违反条件的区别，使后续判读能够识别证据的使用边界。

### 证据缺口如何被发现并补足

初始图谱可能存在抽取遗漏，初次检索也可能缺少关键依据。研究问题是如何围绕当前诊断问题确定缺口，开展定向检索及原文核验，并判断新证据是否足以改变原有结论。

### 不同资料如何形成一致的诊断判断

影像、认知评估、检验和病史提供不同类型的事实。研究问题是如何让各智能体共享事实、条件状态和依据，发现需要进一步解释的冲突，并由主智能体完成有证据支持的综合判读。

### 待验证的作用假设

| 方法环节 | 预期减少的错误 | 对最终准确率的验证 |
| --- | --- | --- |
| 条件化知识构建 | 限定丢失或条件绑定到错误声明 | 比较完整声明与去除条件信息的系统 |
| 患者适用性判断 | 使用违反条件或条件未明的证据 | 比较启用与关闭条件判断的系统 |
| 定向补查与原文核验 | 关键知识遗漏及未经核验的补全 | 比较启用与关闭补查的系统 |
| 多智能体协作 | 单一分析遗漏及跨资料矛盾未处理 | 比较协作系统与单智能体及独立汇总 |

上述假设需要以最终诊断结果验证。中间环节的质量评估和病例分析用于解释准确率变化，也用于识别新引入的错误，例如条件误判、噪声证据增加或协作形成错误共识。

## 3 条件化医学知识构建

### 文档结构与医学语义

文档解析保留正文、标题、表格、角标、脚注及其位置与关联信息。在此基础上构建内容结构图 Gs，用于表达文档单元及其结构关系；同时构建医学语义图 Gm，用于表达医学概念、候选关系和声明之间的语义联系。

知识构建的关键是将分散的限定绑定到正确的声明。PPT 中的抽象示例为正文中的“X 支持 D”，结合标题中的方法 M 及脚注中的排除事项 E。绑定需要利用结构关系、实体联系和语义相似性，避免仅按位置邻近分配条件。

匹配评分可采用如下记号表达 PPT 中的加权思路。权重、阈值和约束的具体形式在实现阶段确定，并通过验证数据选择。

$$S_{ij}=aS_{struct}(i,j)+bS_{entity}(i,j)+cS_{semantic}(i,j)$$

其中，i 与 j 表示待匹配的文档单元或候选声明；三个评分分别表示结构、实体和语义联系。在匹配评分基础上，通过约束选择完成绑定，并保留绑定所依据的原文位置。

### 完整知识声明

$$K=(h,r,t,C,U,P)$$

| 字段 | 含义 | 保存内容 |
| --- | --- | --- |
| h | 主体 | 标准化医学概念及原文表达 |
| r | 关系 | 声明表达的医学关系 |
| t | 客体 | 关系指向的概念或诊断对象 |
| C | 适用条件 | 条件内容及 AND OR NOT 等逻辑关系 |
| U | 诊断用途 | 该声明支持的分析任务或用途 |
| P | 来源 | 文档标识和支撑声明及条件的原文定位 |

PPT 已展示 AND 与 NOT 的条件结构；OR 是后续按语料需要确定的扩展。示意图中的 T 等条件变量需要结合真实语料明确含义，不预设为固定阈值。来源定位的具体粒度可按文档、章节、页码和文本片段实现。

### 图谱与向量索引

完整声明及原文片段分别建立向量索引，图谱保留声明、概念、条件、用途和来源之间的结构联系。检索结果应能返回对应声明及其原文依据。缺少可核验来源的候选内容应保留待核验状态。

构建质量重点检查限定是否被找出、条件作用范围是否正确、逻辑是否保留以及来源是否能够定位。图谱规模用于描述资源，不作为诊断准确率提升的替代证明。

## 4 面向患者的证据检索与条件判断

### 患者事实与查询用途

患者资料经分析后形成事实集合 F。事实应保留所属资料、时间、测量方法及缺失状态，以支持后续条件判断。原始影像如何转化为影像所见，需要在实现中明确所用工具或模型及其输出接口。

$$q=(F,U_q)$$

Uq 表示当前检索用途。PPT 中的示例包括病史要点对应诊断相关分析、量表特征对应认知评估、影像所见对应影像表型分析、检验指标对应鉴别诊断。用途可随诊断问题变化，同一事实集合可以产生不同检索请求。

### 混合检索

向量检索根据语义联系获得候选声明与原文片段，图谱检索利用概念、关系、条件、用途及来源连接获得候选证据。具体的召回合并、去重、检索范围和候选数量需要在实现中固定。

PPT 中的排序思路同时考虑相关性、诊断用途和患者条件匹配。

$$S_i=\alpha s_{rel}(q,K_i)+\beta s_{use}(U_q,U_i)+\gamma s_{cond}(F,C_i)$$

三个分量分别表达查询与知识的相关程度、用途一致程度及患者事实与知识条件的匹配程度。评分归一化、权重和最终选择策略需在验证阶段确定。违反条件的知识应明确标记适用限制，避免被当作正向支持依据。

### 条件状态与后续动作

| 状态 | 判断含义 | 后续处理原则 |
| --- | --- | --- |
| 满足 | 已有事实支持所需条件且未触发排除事项 | 结合知识用途纳入相应分析 |
| 未知 | 关键条件缺少事实或无法可靠判断 | 保留未知状态并提出具体信息需求 |
| 违反 | 已有事实与必要条件冲突或触发排除事项 | 标记适用限制并避免错误引用 |

缺失记录不能自动作为否定事实。例如，没有记录排除事项 E，并不等于已经确认不存在 E。必要条件和排除条件的判断需要保留这种区别。组合条件的判断规则、患者事实冲突的处理和状态更新规则需要形成明确的实现约定。

证据返回结果拟包含声明标识、原文依据、用途、条件状态及未解决事项。条件判断属于可能出错的环节，需要同时验证其自身正确性及对最终诊断的影响。

## 5 需求驱动的证据补查与图谱更新

### 两类缺口与处理方向

患者信息缺口是指判断某项条件或诊断问题所需的患者资料尚未提供。系统应指出所缺事实，并在既有资料中继续查找或形成补充信息建议。未提供的检查结果保持未知，不由模型生成假定值。

知识缺口是指当前知识资源缺少分析所需的声明、条件或连接。系统围绕缺失问题检索文献及指南，将找到的原文作为补充依据。患者信息补查与知识补查分别记录，避免将二者混用。

### 候选连接与原文核验

PPT 使用 ComplEx 对潜在连接评分，用于提出值得进一步核查的候选边。其输出需要经过来源文献检索和原文核验，再决定是否加入图谱。核验应检查关系方向、否定表述、适用条件和诊断用途，并保存支撑位置。

候选边评分表达模型对连接的估计；原文提供可引用的医学依据。高评分候选仍需要核验。没有找到支持原文时，保留候选状态，或停止补入正式知识资源。

### 拟议迭代过程

1. 从当前分析结果中提取尚未解决的关键问题。
2. 判断缺口属于患者事实还是知识资源，并确定补查对象。
3. 开展定向查询，必要时利用连接预测提出检索线索。
4. 核验新增信息，将有效证据及其条件提供给相关智能体。
5. 更新条件状态和诊断判断，并检查是否还存在重要缺口。

停止条件拟包括问题已经得到回答、连续补查没有获得有效新证据、达到预设预算或必要患者信息无法获得。最大轮次、候选数量和有效证据标准需要在实现前确定，并在测试前固定。

### 实验期间的知识更新

诊断实验应记录初始图谱版本、知识语料、检索参数和补查记录。针对测试病例找到的证据可用于该病例的分析，但患者真实诊断标签不得作为检索线索或图谱补全依据。

为避免不同测试病例的运行顺序改变结果，主要对比实验拟采用冻结的初始图谱及每个病例独立的临时补充知识。持续更新的全局图谱作为单独设置评价，记录更新顺序及版本。这一安排属于实验建议，不代表当前已经实现。

## 6 多智能体协作与综合诊断

### 智能体分工

PPT 的系统架构包含影像、认知、检验、知识、随访和医学主智能体；检索图还展示了临床分析角色。下表给出拟议职责，具体角色是否合并以及工具接口需在实现中确定。

| 角色 | 主要关注内容 | 提交给协作过程的结果 |
| --- | --- | --- |
| 临床分析智能体 | 病史 症状 用药与临床背景 | 临床事实 初步判断及待查问题 |
| 认知智能体 | 认知 情绪和功能量表 | 量表特征及评估依据 |
| 影像智能体 | 影像所见及专用工具输出 | 影像事实及其解释需求 |
| 检验智能体 | 生化 生物标志物及相关检验 | 检验事实与鉴别线索 |
| 知识智能体 | 知识检索 条件判断及来源核验 | 适用证据 条件状态与知识缺口 |
| 随访智能体 | 纵向病程和既往检查变化 | 时间顺序及变化线索 |
| 医学主智能体 | 各方分析和证据整合 | 最终结构化诊断与辅助报告 |

### 协作与判断更新

各智能体首先根据可用资料提交患者事实、初步判断、所用证据和未解决事项。主智能体汇总待解决问题，并将证据需求交由相关角色处理。新资料或核验后的知识返回时，相关智能体重新判断适用条件，更新自身分析。

对相互冲突的结论，应定位产生冲突的患者事实、时间、方法和证据，而后通过补查或重新判读处理。诊断判断的修订需要说明新增或被排除的依据。多轮讨论带来的准确率收益需要与增加模型调用次数的收益区分评价。

### 输出结构与评分对象

最终报告包括辅助判读、关键证据、推理依据及风险建议，并展示对诊断仍有影响的未知条件。每个主要结论应能定位对应患者事实和适用医学证据。

结构化输出拟包含主要诊断标签、候选诊断和证据标识等字段。主要准确率评价使用预先约定的主要诊断字段，不依据报告语言是否流畅评分。候选诊断覆盖率和报告质量可以单独评价。

对无法给出确定结论的病例，需预先规定输出与计分方式，并记录全部输入病例。固定分类任务中，拒答或缺少有效标签计入错误；若另设允许拒答的任务，同时报告覆盖率及已作答病例准确率，避免选择性作答造成比较失真。

## 7 准确率评价与拟议对比实验

### 主要评价指标

在单标签诊断任务中，主要指标为诊断准确率 Acc，即正确预测病例数占全部评价病例数的比例 [1]。多病因共存若被定义为多标签任务，应另行确定标签表示和准确率计算规则。

$$Acc=\frac{N_{correct}}{N_{total}}$$

$$\Delta Acc=Acc_{system}-Acc_{baseline}$$

主要结果报告系统和基线的准确率、准确率绝对差值及其不确定性。差值以百分点表达，并列出评价病例数。具体目标增幅不预设虚构数值，需要根据数据规模、基线表现和研究要求确定。

辅助报告各类召回率、宏平均 F1、平衡准确率及混淆矩阵，用于观察整体准确率变化是否伴随某些疾病类别表现下降。平衡准确率按类别召回率的平均值计算 [1]。这些指标支持解释，不取代已确定的首要目标。

### 数据与比较条件

评价前固定目标疾病、标签来源、诊断时间点和可用输入。同一患者的不同记录及不同模态资料按患者分组划分，避免跨训练与测试重复；分组划分可使用组互斥策略实现 [2]。纵向任务仅使用诊断时间点之前允许获得的信息。

所有方法使用相同测试病例。统一基础模型、资料处理工具、知识语料及输出格式；同一条件下比较准确率，同时记录调用次数、检索次数、输入输出量和运行时间。多智能体比较增加计算预算匹配的设置，判断收益是否仍然存在。

### 建议的主要基线

| 设置 | 核心配置 | 比较目的 |
| --- | --- | --- |
| 基础模型 | 同一模型分析同一患者输入 | 判断完整系统的总体增益 |
| 文本 RAG | 同一语料的文本检索与单智能体 | 判断结构化知识方法的增益 |
| 普通图谱检索 | 去除显式条件建模的图谱检索 | 判断条件化知识的增益 |
| 条件图谱单智能体 | 保留条件检索并使用单智能体 | 判断协作带来的额外增益 |
| 完整系统 | 条件图谱 补查及多智能体协作 | 评价最终方案 |

参数和提示词在验证阶段选择，测试结果不用于反复调参。主要结论结合患者级配对结果、置信区间和重复运行稳定性判断，不以一次运行中的微小差值作为充分证据。

## 8 消融实验与错误分析

### 方法贡献的独立验证

完整系统的总体结果需要进一步拆解。消融实验在尽量保持其他条件一致的情况下关闭一个机制，观察最终准确率及相关中间指标的变化。

| 消融设置 | 主要观察问题 | 配套中间指标 |
| --- | --- | --- |
| 去除结构与语义的联合绑定 | 条件错绑是否影响诊断 | 条件绑定正确性 |
| 去除条件化知识表示 | 限定信息缺失是否影响诊断 | 知识声明完整性 |
| 保留条件但关闭患者条件判断 | 条件实际使用是否带来增益 | 条件状态判断正确性 |
| 去除诊断用途项 | 用途匹配是否改善证据选择 | 任务相关证据质量 |
| 关闭需求驱动的补查 | 知识缺口是否限制准确率 | 补查新增有效证据比例 |
| 关闭候选连接预测 | 连接预测是否改善补查 | 核验通过率及补查收益 |
| 改为独立分析后直接汇总 | 协作更新是否带来增益 | 冲突解决与判断修订情况 |

原文核验可在独立候选集上比较核验前后的正确率。如需评价关闭核验的诊断影响，使用隔离的实验副本，避免未经核验的候选写入主要实验知识资源。该设置检验错误补全对结果的影响。

### 特定病例子集

拟分别分析条件信息分散于脚注或表格的病例、存在关键排除条件的病例、患者资料缺失的病例、不同模态线索冲突的病例，以及初始图谱缺少关键连接的病例。子集定义和标注规则在查看最终结果前确定，避免根据系统表现临时筛选有利病例。

### 诊断错误的来源

错误分析覆盖患者事实提取、知识抽取、条件绑定、候选召回、适用性判断、原文核验和最终综合判读。每个错误病例记录错误首次出现的环节，以及后续环节是否识别或放大该错误。

同时检查基线错误而系统正确的病例，以及基线正确而系统错误的病例。对前者说明哪项事实或证据促成修正；对后者说明条件误判、噪声检索或协作偏差如何引入新错误。修复建议回到具体模块，避免只通过修改最终提示词掩盖上游问题。

### 成功判据

系统在预先固定的主要诊断任务上取得可信的准确率增益，且关键消融能够支持相应方法机制的作用，才足以支撑研究主张。若中间质量改善但最终准确率未提高，需要重新检查错误来源、目标任务及方法作用环节。

## 9 研究贡献与实施决策

### 拟形成的研究贡献

方法层面拟形成结合文档结构与医学语义的条件绑定方法，以及融合相关性、诊断用途和患者条件状态的证据检索方法。需求驱动补查通过候选连接、原文核验及知识更新缓解证据缺口。系统层面将这些机制用于多智能体患者分析与综合诊断。

结果层面的核心贡献是经对比及消融验证的诊断准确率提升。创新性需要进一步与已有研究比较；准确率收益需要实验验证。知识表达更完整和报告更易追溯，可以作为支持性贡献描述。

### 实施前需要固定的事项

| 决策事项 | 需要明确的内容 |
| --- | --- |
| 疾病与主要任务 | 覆盖疾病 标签集合及主要诊断字段 |
| 数据与真实标签 | 数据来源 患者数量 标签依据及评价时间点 |
| 患者事实获取 | 各模态处理工具 输出形式及缺失处理 |
| 知识来源 | 文献及指南范围 版本和来源定位粒度 |
| 条件规则 | 条件字段 组合逻辑及未知冲突处理 |
| 模型与协作 | 基础模型 角色边界 交互格式和停止条件 |
| 图谱补查 | 候选连接生成 核验规则及更新边界 |
| 实验口径 | 基线 预算 参数选择及增益判断标准 |

### 推进次序

首先确定能够提供可靠诊断标签的主要任务，固定输入与评价规则并建立基线。随后完成患者事实、完整知识声明和证据输出的统一接口，形成可执行的最小流程。

在最小流程上逐步加入条件绑定、适用性判断和补查，观察错误病例是否得到修正，再加入多智能体协作并控制计算预算。各阶段保留统一评价集与运行记录，阶段收益在验证数据上检查，最终方案固定后进行独立测试。
