# NeuroGRA 静态工作台预览

## 已接入的系统工作台

在项目根目录运行 `python -m neurogra.clinical.web --port 8767`，访问 <http://127.0.0.1:8767/>。
该入口提供真实 RWE 分析、任务进度、历史报告和依据追溯；完整说明见 `docs/Web工作台运行说明.md`。
`workbench-api.js` 仅由系统入口加载；下面的 HTML 文件继续支持独立离线预览。

## 最新 RWE 工作台

打开 `rwe-workbench.html` 查看新页面。它是独立 HTML，包含全部样式、图标和交互，无外部依赖。

- 默认展示独立验收的脱敏流程快照，不嵌入患者身份或临床原始字段。
- 包含患者编号入口、流程回放、智能体状态、报告、陈述检索、知识来源和依据面板。
- 可同时导入 `report.json` 和 `provenance.json`；仅允许关联同一患者、同一运行的文件。
- 本地导入后，可逐条查看原始观察、RWE 字段定位、知识原文、适用条件与限制，并导出报告 JSON。
- 输入其他编号会清空当前患者内容；页面没有连接后端，不执行实际分析。
- 采用桌面三栏与手机单栏布局，支持键盘页签切换、依据弹窗焦点限制与 Escape 关闭。

运行下方本地服务后访问 `http://127.0.0.1:8765/rwe-workbench.html`。

本次真实报告的离线预览位于 `output/frontend-preview/neurogra-report.html`。该文件含本地报告数据，位于 Git 忽略目录；可以直接用浏览器打开。

## 原有合成病例原型

双击 `index.html` 即可在浏览器打开。CSS、JavaScript、合成病例与报告数据均内嵌，无需安装前端依赖，也没有外部网络资源。

也可以在项目根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory frontend
```

打开 `http://127.0.0.1:8765`。

页面包括病例概况、资料页签、四类 Agent 状态、待核实事项、自然语言综合报告、检索来源与分析过程。支持本地 JSON 导入预览、阅读弹窗、复制、文本导出和打印。支持桌面双栏与手机单栏布局。

默认演示内容来自合成病例 `ca78e6494d7b4147b1f44e3a70193bc2` 的真实运行记录，自然语言报告来自补写运行 `91ee712cec144b77b5f77d6b35014172`。它们是构建本页面时的静态快照。保留“部分完成”和“复查未完成”，不表示所有分析已通过。

“演示分析过程”只回放状态，不调用模型。导入 JSON 后只显示该文件资料，不继承演示病例的报告、知识来源或分析状态。任意中文字段可通过“查看原始资料”查看；页签只做同名字段展示，不执行语义分类。数据仅保留在当前页面内存中，刷新后恢复默认演示。

本页面尚未连接后端 API。没有原始影像文件时，不展示 DiaMond 已推理的状态。
