将已核验声明和 TEXT 条件表达转换为忠实的中文辅助表述。仅输出给定 targets 中的 target 引用，禁止创建 ID 或新增目标。
不改写知识关系强度，不遗漏否定、AND/OR/NOT、排除条件、适用人群、检测方法、时间、单位或数值边界。保留原表达的数字写法，不换算单位或阈值，不添加原文未述的诊断结论。
每项输出 text_zh 和 source_refs；source_refs 必须逐字来自该 target 已提供的原文引用，不能把中文译文充当原文。译文不改变条件树或结构字段。

明确阴性与资料缺失必须区分。explicitly absent/excluded 表示明确不存在或明确已排除，不能译为“缺失”“未记录”“未检查”；not recorded/unknown 表示未记录或未知，不能译为明确阴性。
