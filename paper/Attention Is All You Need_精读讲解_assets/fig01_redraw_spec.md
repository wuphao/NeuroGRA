# Figure 1 中文重绘规格

- 原图：Transformer 完整 encoder-decoder 架构。
- 左侧编码器：输入 → 输入嵌入 → 加位置编码 → N×（多头自注意力 → 残差加和与层归一化 → 前馈网络 → 残差加和与层归一化）。
- 右侧解码器：右移目标序列 → 输出嵌入 → 加位置编码 → N×（带遮罩多头自注意力 → Add & Norm → 编码器-解码器多头注意力 → Add & Norm → 前馈网络 → Add & Norm）→ 线性层 → Softmax → 输出概率。
- 跨模块连接：编码器顶部输出同时接入解码器中间的多头注意力，作为 K/V。
- 残差连接：每个注意力/前馈子层外都有跳连。
- 层数：编码器和解码器都标记 N×，论文中 N=6。
- 不得改变：左右顺序、三种注意力所在位置、交叉注意力连线、右移输出和最终 Linear/Softmax。

## 验证记录

- 通过：编码器/解码器左右位置、N× 标记、子层顺序、残差回路、编码器到交叉注意力的连线、右移输出和 Linear/Softmax 均保留。
- 通过：中文标签可读，未增加原图不存在的模块。
- 注：重绘用“残差相加与层归一化”显式解释 Add & Norm，属于等价翻译。
- 第一次生成后技术复核认为 cross-attention 的 K/V 分路和 Q 来源不够显式，因此进行第二次定向重绘。
- 第二次验证通过：编码器顶层输出以两条箭头分别标记 K、V，decoder 下层输出以单独箭头标记 Q，三者进入交叉注意力；其他结构未改变。
